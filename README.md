# BAMORA

Premium marketplace — one store, many merchants, invisible to customers.

## Requirements

- Node.js 20 or newer
- pnpm (recommended) or npm

## Quick start

```bash
# with pnpm
pnpm install
pnpm dev:customer

# or with npm
npm install
npm run dev:customer -w @bamora/customer
```

Open [http://localhost:3000](http://localhost:3000) for the customer opening experience.

See [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) for full specification.
